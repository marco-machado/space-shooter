# Project Purpose

This is a **space shooter game** built with Phaser.js 3.x and Vite build tooling. The game combines classic arcade action with modern progression mechanics.

## Key Features:
- Multiple weapon types (Laser Cannon, Plasma Gun, Missile Launcher)
- Diverse enemy varieties (Scout, Fighter, Bomber, Boss enemies)
- Player progression system with XP and leveling
- Power-up systems (temporary and permanent)
- Simple Entity Component System architecture
- Browser localStorage for data persistence
- Development phase uses colored rectangles for rapid prototyping

## Target Platform:
- Web browsers (desktop and mobile)
- HTML5 Canvas with WebGL rendering
- Client-side only with localStorage persistence
- Modern ES6+ JavaScript with Vite bundling
